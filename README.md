# સ્માર્ટ હાજરી પત્રક — PWA

આ પ્રોજેક્ટ Android/Chrome માં install કરી શકાય તેવી Gujarati Progressive Web App છે.

## GitHub Pages પ્રકાશિત કરવું
1. Repository → **Settings** → **Pages** ખોલો.
2. **Build and deployment → Source** માં **GitHub Actions** પસંદ કરો.
3. **Actions** ટૅબમાં “Publish Smart Attendance PWA” workflow પૂર્ણ થાય તેની રાહ જુઓ.
4. સાઇટ: https://brparvesechuda-star.github.io/smart-attendance-pwa/

## Android માં ઇન્સ્ટોલ
સાઇટ Chrome માં ખોલો → menu (⋮) → **Install app** અથવા **Add to Home screen**.

## નોંધ
- PWA offline shell cache કરે છે; પરંતુ live multi-device sync માટે ઇન્ટરનેટ અને મૂળ sync/configuration સેવાઓ જરૂરી છે.
- આ જાહેર repository માં વાસ્તવિક વિદ્યાર્થીઓની વ્યક્તિગત માહિતી, પાસવર્ડ કે secret keys ન મૂકો.
